# AI-DLC 코어 프레임워크

AI-DLC는 **AI와 사람의 협업**이 만드는 새로운 개발 표준입니다. AI의 속도와 인간의 판단이 균형을 이루는 체계적인 프레임워크입니다.

**AI와 사람의 협업 방식**

AI-DLC에서 AI와 사람은 각자의 강점을 살려 함께 설계하고 검증하며 운영합니다.

**AI의 역할**

- **계획 수립**: 요구사항을 분석하고 작업을 분해합니다
- **아키텍처 제안**: 최적의 설계와 기술 스택을 제안합니다
- **개발 프로세스 조율**: 단계별 실행 계획을 수립합니다
- **코드 생성**: 설계를 바탕으로 실제 코드를 작성합니다

**사람의 역할**

- **검증**: AI가 제안한 계획과 설계를 검토합니다
- **의사결정**: 비즈니스 목표에 맞는 최종 결정을 내립니다
- **감독**: 품질과 방향성에 대한 최종 책임을 담당합니다
- **승인**: 각 단계의 산출물을 확인하고 승인합니다

**🔵 INCEPTION: 프로젝트 정의**

**목표**: 비즈니스 의도를 실행 가능한 개발 계획으로 변환

- 도메인에 대한 컨텍스트 구축
- 사용자 스토리로 의도 구체화
- 작업 단위로 계획 수립

**🟢 CONSTRUCTION: 구축**

**목표**: 설계를 프로덕션 품질의 코드로 구현

- 도메인 모델 (컴포넌트 모델)
- 아키텍처 컴포넌트 추가
- 코드 생성 및 테스트

**🟡 OPERATIONS: 운영**

**목표**: 안정적인 프로덕션 환경 구축

- 배포를 위한 파이프라인 생성
- IaC로 프로덕션 배포

**AI-DLC의 관된 개발 방식**

AI-DLC는 모든 개발에 적용되는 일관된 접근법을 제공합니다:

**AS-IS: 사람 주도 개발**

- 전문 영역별 분리된 개발 (사일로)
- 주/월 단위의 긴 개발 사이클
- 사람이 모든 프로세스를 주도

**TO-BE: AI 주도 개발**

- 통합된 개발 영역
- 시간/일 단위의 빠른 개발 사이클
- AI가 프로세스를 주도하고 사람이 검증

**AI-DLC의 주요 이점**

**개발 속도 향상**

- 주/월 단위 작업을 시간/일 단위로 단축
- 최대 10배 이상 생산성 증가

**종단간 품질 보장**

- DDD/BDD/TDD 통합으로 Best Practice 구현
- 정확한 판단으로 빠른 반복
- 지속적 명확화로 정확한 의도 구현

**개발자 역량 강화**

- 고부가가치 의사결정에 집중
- 다양한 영역으로 전문성 확장

**비즈니스 민첩성**

- 빠른 기능 구현 및 배포
- 시장 요구에 신속 대응
